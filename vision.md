# AtiqLabs Vision

## Mission

Develop professional engineering software for
power cable system analysis, design, and optimization.

The software shall provide validated engineering
calculations based on international standards while
remaining intuitive, educational, and extensible.

---

# Product

## AtiqLabs Power Cable Engineering Suite

A desktop engineering application for power cable
design and analysis.

---

# Version 1.0

## Goal

Release a validated IEC 60287 cable ampacity
application for Concrete Duct Bank installations.

### Features

- IEC 60287 Ampacity
- Cable Editor
- Cable Cross Section Drawing
- Concrete Duct Bank Editor
- Duct Bank Drawing
- Engineering Results
- PDF Report
- Save/Open Projects
- Validation against Riyadh Cables Reference Case
